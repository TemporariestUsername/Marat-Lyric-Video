# Type score

The blueprint for the typography, line by line. For each lyric line:
- **voice**: who speaks, which sets the face;
- **hero**: the word that dominates the frame;
- **behaviour**: what the type does, from the toolkit below;
- **picture**: the print it lives with.

The lyrics are set exactly as in `assets/lyrics.txt`. CAPS mean shouting.

## Voices

| voice | face | colour on the page |
|---|---|---|
| MARAT | Fell roman for speech; Didot (Paris, 1780s) for shouts | ink on paper; paper on dark prints |
| CROWD | heavy condensed wood-type capitals, broadside stacks | ink, plus red for the chant |
| HAND | Marat's handwriting: script written by quill, stroke by stroke | iron-gall ink, browning |
| JUDGE | indictment layout: small caps, numbered clauses, rules | cold black, no ornament |
| CORDAY | fine Didot italic, calm, never shouts | ink, pale |
| ÇA IRA | broadside song sheet, stacked Didot italic | the only tricolour in the film |

## Toolkit

| # | behaviour | what it does |
|---|---|---|
| T1 | SET+PRINT | letters drop into a compositor's stick mirrored (type is set backwards), then the platen slams on the kick and the line prints the right way round |
| T2 | NAMES | a proscription list: each name stacks, a ☞ manicule points at it, and red ink strikes it through on the hit |
| T3 | FEVER | letters shimmer with heat; ink blots bloom; the hero word scales at the lens |
| T4 | SEWER | words sink under a waterline, with a dripping, rippled reflection below it |
| T5 | LEDGER | the lyric is set as an account: tally strokes and a total line summed in red |
| T6 | QUILL | handwriting drawn stroke by stroke, with ink pooling at the pauses; the French original ghosted beneath |
| T7 | EYES | the counters of O/A/E fill with Marat's eye; "gouge" punches letters out |
| T8 | WALL | each chant adds a row of wood type until the frame is solid |
| T9 | KNIFE | the word is sliced on a clean diagonal and the halves slide apart |
| T10 | FILL | blood rises inside the letterforms, then overflows them |
| T11 | PATH | type runs along a line in the print: the pikes, the tub's rim, the blade |
| T12 | FLOAT | words drift on bathwater and ripple; submerged letters darken |
| T13 | COLUMN | the line is typeset into the newspaper's page grid (masthead, rules, drop cap) and the camera travels the page |
| T14 | STAMP | a single word slammed as a rubber stamp (the chorus parentheticals) |
